## 6. Предварительные настройки первой версии (исторический срез)

Таблица ниже сохранена из v0.6.1 для истории. При расхождении использовать принятые значения §11; подтверждённая пользователем модель навигации отмечена отдельно.

| Параметр | Предложение |
|---|---|
| Базовый поиск | Omnisearch, приоритет имени файла и согласованных aliases; совпадения в тексте отдельно |
| Режимы retrieval | `narrow` для точечных вопросов; `deep` для исследования и записи знаний |
| Семантический поиск | RAPTOR по Markdown-иерархии article → section → subsection → paragraph/chunk |
| Адресное чтение | По умолчанию section/paragraph через `obsidian-fragment-reader`; полная статья — только по необходимости |
| Hybrid retrieval | Omnisearch + terms + RAPTOR + Dataview/Bases + MOC/graph |
| MOC discovery | Обязательные `summary` и `terms` |
| HUB | Обязательная пара `.md + .canvas`; `.md` — описание и машинный индекс |
| Структура статей | Смысловые абзацы, явные заголовки, callouts для важных блоков |
| Каталог запросов | `System/Queries/README.md` + переиспользуемые Dataview/Bases определения |
| Глубина контекста | 2 перехода |
| Направление | Исходящие и обратные ссылки |
| Объём обхода | До 30 уникальных заметок и до 10 подходящих соседей на одну заметку |
| Бюджет чтения | Отдельный лимит по выбранной модели; считать фактически прочитанный объём |
| Неявные связи | Показывать отдельно от существующего графа |
| Новые статьи | Черновики, число определяется самостоятельными вопросами исследования |
| Старые статьи | Адресные предложения изменений |
| Внешние источники | Включать по выбранному режиму задачи |
| Навигация — подтверждено | Иерархические MOC с ракурсами; HUB в виде Canvas с MOC и отдельными статьями |
| Реализация навигации — предложение | MOC в Markdown; HUB в нативном `.canvas`; опциональная Markdown-карточка HUB для метаданных |
| Метаданные | Компактное общее ядро и дополнительные поля по типу заметки |
| Повторный запуск | Переиспользовать ранее созданные заметки и обновлять только изменившееся |

## 8. Что уточнить в первую очередь (исторический срез)

Это список вопросов на момент v0.6.1. Их рабочие ответы в §11; фактические свойства vault нужно обнаружить при bootstrap. Исторический список:

1. **G1–G2:** среда Claude и способ подключения.
2. **G5–G6:** область доступа и режим создания/применения изменений.
3. **S1:** точное значение поиска «по названию».
4. **C1–C2:** глубина и направления обхода.
5. **R1:** границы исследования и внешние источники.
6. **A1, A6:** размер статей и форма результата.
7. **M1:** действующая схема метаданных.
8. **O7–O9, H7–H9:** число родителей MOC, словарь ракурсов, принадлежность статей и правила компоновки Canvas. Формат HUB `.md + .canvas` уже подтверждён.
9. **RAPTOR:** embedding model/vector store, правила инкрементального обновления и размеры leaf chunks после разбиения по структуре Markdown.
10. **Retrieval budgets:** значения по умолчанию для `narrow` и `deep`, top-k и критерии ранней остановки.
11. **Callouts:** нужен ли фиксированный словарь пользовательских типов поверх стандартных типов Obsidian.
12. **Query registry:** точная папка `System/Queries` и политика автоматического добавления доказавших полезность запросов.

Остальные вопросы можно заполнять последовательно по скиллам. Удобный формат ответа: `S1: ...`, `C1: ...`, `R1: ...`. Если решение пока не принято, отметить «предложи варианты».

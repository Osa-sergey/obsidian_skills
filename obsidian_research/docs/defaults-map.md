# Карта дефолтов

Нормативные значения находятся в [§11 спецификации](spec/defaults.md). Этот файл только помогает найти их и указать место настройки.

| Группа | ID | Настройка/решение |
|---|---|---|
| Окружение | G1–G7 | Claude Code local-first; capability discovery; области vault profile |
| Поиск и граф | S1–S6, C1–C6 | title priority, fallback, глубина, включение связей |
| План внешнего поиска | `REQ-RET-0004–0005` | явный запуск, scope HUB/MOC, 6–12 разных запросов, без автоматического веб-поиска |
| Исследование и запись | R1–R6, A1–A6, U1–U6 | evidence, черновики, patch/apply |
| Ссылки и свойства | L1–L6, M1–M6 | vocabulary, YAML, additive schema |
| Навигация | O2–O10, H2–H10 | один основной parent, пара HUB, инкрементальный Canvas |
| Оркестрация и запросы | W1–W6, Q1–Q6, V1–V11 | workflow modes, query registry, managed blocks |
| Индекс и бюджеты | RAPTOR, retrieval budgets, callouts; `REQ-RET-0001–0002` | локальный индекс, file-level full replacement после записи, `source`/`source_path`, top-k |

Переопределение значений допускается через vault profile либо явный параметр вызова, если не нарушает инварианты из `CLAUDE.md`. Пути, установленные плагины, версии, существующая YAML-схема и стиль заметок выясняются при bootstrap, а не угадываются. Настройка модели embeddings — заменяемый адаптер; смена модели требует отдельной миграции индекса. Исторические вопросы в §2–3 сохранены с ID; действующие ответы находятся в §11 и [реестре новых требований](spec/requirements-registry.md).
